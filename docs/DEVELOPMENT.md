# Разработка и эксплуатация

## Среда и команды

Node.js 20+, современный браузер с ESM, IndexedDB, structuredClone и crypto.randomUUID.
Сторонних пакетов нет: `npm install` и сборка не нужны. Команды выполнять из корня приложения.

```powershell
# Рабочий сервер
node server.mjs

# Проверка с отдельным браузерным хранилищем
node server.mjs --port=4668

# Все тесты логики
npm test

# Проверка синтаксиса модуля
node --check app.mjs
```

Полная проверка синтаксиса модулей в PowerShell:

```powershell
Get-ChildItem -LiteralPath . -Filter *.mjs | ForEach-Object {
  node --check $_.FullName
  if ($LASTEXITCODE -ne 0) { throw "Ошибка синтаксиса: $($_.Name)" }
}
```

`Start.cmd` вызывает `Start.ps1`: проверяет `/health`, запускает Node скрыто, сохраняет
`.runtime/server.pid`, `.runtime/server.log`, `.runtime/server-error.log` и открывает браузер.
Запуск без новой вкладки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1 -NoBrowser
```

`Stop.ps1` проверяет командную строку процесса по сохранённому PID и завершает подходящий
`server.mjs`. Сервером, запущенным вручную без этого PID-файла, скрипт не управляет.
Ручной сервер останавливать через Ctrl+C; не завершать все процессы Node.

## Сервер и обновление

`GET /health` возвращает `{app: "entry-navigator", version: "0.1", port}`.
Это проверка сервера, а не доступности IndexedDB.

Ресурсы читаются с диска при запросе, задан `Cache-Control: no-store`.
После правки JS/CSS/HTML обновить страницу. Hot reload и service worker отсутствуют.
После изменения `server.mjs`, включая allowlist, перезапустить процесс.
Новый браузерный модуль включать в `allowed`, иначе его импорт получит 404.

Сервер слушает только `127.0.0.1`. CSP разрешает локальные скрипты, локальные/inline-стили,
изображения `data:`/`blob:`. Документация, тесты и `.runtime` через HTTP не выдаются.
Внешние ресурсы добавлять осознанно, сохраняя необходимые ограничения CSP.

## Проверка UI по затронутой части

Использовать синтетические записи на `http://127.0.0.1:4668`. Там могут оставаться данные
прежних проверок — не считать origin заведомо пустым.

**Конструктор:** создать схему, добавить вопрос и третий ответ, задать разные переходы и итоги.
Оставить переход пустым, сохранить черновик, перезагрузить страницу и нажать «Продолжить»:
текст, пустой переход и выбранный блок должны восстановиться. Корректный граф можно оставить
черновиком; «Сохранить готовую» требует проверки и не создаёт разбор в журнале.
Ошибка сохранения не должна закрывать редактор и показывать успешное сохранение.
Проверить сообщения для отсутствующего перехода и цикла. Запустить разбор, пройти ветку,
зафиксировать наблюдение либо тестовую сделку. Перезагрузить страницу и открыть запись.
После изменения библиотеки запись должна сохранить прежние вопросы и revision.
Удаление схемы не должно удалять созданные по ней разборы.

**Карта переходов:** завести итог раньше связанного вопроса, затем задать «Да» в вопрос,
«Нет» в итог. Ветки должны идти без перекрещивания у выхода; подписи относятся к своим
линиям. Проверить общий итог, переход через несколько слоёв, выбор блока нажатием и
прокрутку широкой карты на узком экране. Длинные названия вопросов/итогов и ответов должны
показываться полностью с переносами, без многоточий и наложения на соседние блоки или повороты
стрелок. Проверить ручной перевод строки и длинное слово. Изменение карты не должно менять
сохранённый граф.

**Галереи подсказок и ответов:** открыть старую схему с одиночной картинкой — она должна
показываться без перезаписи. Добавить к подсказке и ответу по несколько файлов одной пачкой,
сохранить, перезагрузить редактор и запустить схему. Все миниатюры должны оставаться доступны.
Увеличение не выбирает радиоответ. Замена/удаление одной картинки не меняет соседние или старый
разбор. Проверить JSON round-trip, предел 10 файлов на галерею, 5 МиБ на файл и ошибки чтения.
Перетаскивание пачки должно добавлять её целиком; смешанная пачка с ошибочным файлом не
должна частично добавляться. Для журнала учитывается число уже прикреплённых файлов.
Drop вне области не открывает файл вместо приложения. Проверить широкую и узкую вёрстку.

**Примеры:** убрать один встроенный пример, перезагрузить страницу и проверить, что второй остался.
Убрать второй: появляется пустое состояние и восстановление. Восстановить оба.
Отмена подтверждения не меняет видимость; собственные схемы и разборы остаются доступны.

**Быстрые ответы:** в своей и встроенной схеме нажать вариант — следующий вопрос появляется
без «Продолжить». Последний ответ открывает итог, сохраняя отдельную фиксацию решения.
Вернуться «Назад», нажать уже выбранный вариант: переход работает и следующие ответы сохраняются.
Сменить ранний ответ: прежняя ветка удаляется. Проверить третий вариант, клавиатуру, перезагрузку,
просмотр картинки без перехода и поля зоны перед выбором ответа. Проверить широкий и узкий экран.

**Данные:** добавить исход, суммы и изображение; перезагрузить страницу. Экспортировать JSON,
импортировать на другом проверочном origin и сверить схему, путь и изображение.
Повторный импорт не создаёт дубликатов. CSV проверять отдельно от полного архива.

**Удаление записей:** на синтетических данных открыть одну запись и удалить другую из строки.
Проверить отмену, подтверждение, перезагрузку, вложения, статистику, поиск/фильтры и ошибку записи.
Удалить текущую и последнюю запись: журнал должен оставаться пустым после перезагрузки
и перехода в «Разбор» до явного начала новой записи. Проверить кнопки на узком экране.

**Журнал и вёрстка:** поиск с совпадением и без, очистка поиска, фильтр типа записи.
На широком экране поиск, фильтр и CSV выровнены по нижнему краю и имеют высоту 44 px;
на узком поиск занимает отдельную строку. Подсказка должна читаться полностью.
Проверить редактор, прокрутку карты и внутреннюю прокрутку таблицы на узком экране.
После проверки восстановить viewport и остановить собственные временные QA-серверы.

## Диагностика

| Симптом | Проверка |
| --- | --- |
| После смены адреса журнал пуст | Браузер/профиль, `127.0.0.1` против `localhost`, порт; восстановить экспорт |
| UI не обновился | Перезагрузить страницу; после изменения allowlist перезапустить сервер |
| Пустая страница, 404 на модуль | Консоль браузера, путь импорта, `allowed` в `server.mjs` |
| «Не удалось сохранить» | IndexedDB/квота; экспортировать данные из памяти, не очищая данные сайта |
| Новая версия из JSON не появилась | Совпадающий ID пропускается, импорт не перезаписывает библиотеку |
| Порт занят | Проверить `/health`; не завершать незнакомый процесс ради запуска |
| Sandbox не разрешает localhost | Ограничения исполнения; не менять firewall, bind или рабочий origin для обхода |
| Фоновый запуск не удался | `.runtime/server-error.log`, наличие `node.exe`, затем `/health` |

## Текущие ограничения

- Браузерное хранение; нет файлового backend, синхронизации и автоматических резервных копий.
- Запись отложена на 250 мс: аварийное закрытие до её завершения может потерять последние изменения.
- Нет межвкладочной синхронизации; две открытые страницы могут перезаписать данные из старого состояния памяти.
- Импорт добавляет объекты по одному, без общей транзакции, и пропускает совпадающие ID.
- Встроенный алгоритм имеет номер версии, но не отдельный исполнитель каждой исторической версии.
- В пользовательской схеме направление сделки не выделено типизированным полем.
  Статистика группируется по схеме/версии, а не по смыслу произвольных ответов.
- Библиотека хранится одним массивом, изображения — base64 в записях; большие архивы расходуют память.
- Карта раскладывается автоматически, ручного размещения блоков нет.
- Встроенные диаграммы и маршрут реализованы отдельно; при изменении правил их нужно сверять.
- Интерфейс рендерится строками. При рефакторинге сохранять экранирование, обработку событий и фокус полей.

Это описание существующей реализации, а не согласованный план автоматической переделки проекта.
